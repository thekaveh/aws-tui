aws-tui Architecture

Five enforced layers, four AWS services, one exact-identity handoff path

Layer Contract

Textual reads VMs. VMs call service-owned domain adapters, which perform AWS and filesystem I/O. Infrastructure supplies sessions, client construction, configuration, credentials, and OS-backed stores.

Athena Lifecycle

ContentHostVM awaits Athena shutdown before disposal, allowing owned-query cancellation and worker draining to finish before replacement.

S3 Handoff

Glue locations and Athena customer-S3 results travel as immutable requests carrying the exact configured connection name and region.
